# 观真 · 界面设计约定

视觉以用户指定的纯黑宇宙、向前流动的白色星辰、流体白色光球及全白文字为准。星空和光球用 Canvas 程序化绘制，以响应点击、悬停、状态变化和减少动态偏好。

## 设计系统

- 背景 #030304，面板 #09090c，文字 #ffffff，辅助层级以白色透明度区分。
- 标题：本地 Songti SC / Noto Serif CJK SC / SimSun；界面：系统 PingFang SC / Microsoft YaHei；不访问外部字体或 CDN。
- 宽屏边距 40px，移动端 22px；界面字号 12–16px，标题 28–40px。
- 光球占中心视觉位置，首页文字在其下方，留出大面积黑色空间。
- 唯一导航：左右两颗星辰（对话之星、记忆之星），名称仅在悬停或键盘聚焦时显现；面板内以角落的返回之星关闭。
- 首页唯一开场语：你觉得这个世界是真实的吗？
- 点击光球或继续按钮后：请选择你想感受的真相；小光球为上传入口。
- 上传/结果使用居中对话框；对话/历史使用全屏面板；薄白边、无彩色徽章、不堆叠卡片。
- 结果界面有原图、关注区域、二值掩码，按模型切换；热力图来源于服务端实际模型输出。
- 页面文字全部白色；模型热力图保留原有 JET 颜色，原始图片保留本色，以免改变证据含义。
- 无闪烁、无自动声音。系统减少动态偏好生效；后台标签页与打开面板时暂停绘制。

## 可访问性

所有点击入口使用真实 button/input；对话框支持 Escape、焦点圈定与关闭后焦点返回；星空装饰不进入无障碍树。上传支持键盘选择与拖拽，分析和错误通过 aria-live 告知，结果不只靠颜色表达。

## 界面展示与结果来源

产品文档只使用实际界面截图。[README 的结果展示](../README.md#界面预览)已采用提供的实测素材，包含自研 SAEv1 拼接检测、SAEv2 未篡改样本检测，以及 TruFor 热力图和掩码。分数可对照[推理记录](real-results/inference_results.json)，样本来源可对照[素材清单](real-results/MANIFEST.md)。截图保留原始像素内容，不改写分数或模型输出。

动画光球使用程序化动态细丝。结果不能用样例概率或生成的热力图冒充真实推理；未连接服务时显示真实连接状态。热力图保留原有颜色，以免改变证据含义。

## 与当前实现的区别

- 旧快照中的“没有 JSON API”描述原 `sys.py`，当前 Web 层已提供 `/api/v1`。
- 旧快照提出的 `core/` 拆分方案没有直接采用；当前通过 `server/legacy.py` 适配既有程序。
- 旧快照建议的 mock 模式不是当前产品功能。当前生产代码没有自动模拟结果回退，固定夹具只在测试中使用。
- 当前已实现上传限制、串行推理、私有产物、会话隔离和鉴别任务清理工具。
- 当前没有账号登录或入口密钥门禁，不应照搬旧建议认定这些功能已实现。
- 环境、资源与许可证相关表述属于历史交接记录，实施或使用前应按实际环境及授权文本另行核实。
